# Executive Assistant EPC Oil & Gas Agent

File-based agent untuk OpenHands yang berfungsi sebagai Asisten Eksekutif virtual untuk industri EPC/Minyak & Gas di Jakarta, Indonesia.

## Kemampuan

- **Bahasa**: Bilingual (Bahasa Indonesia & English)
- **Dokumen**: Microsoft Word (.docx), PDF
- **Meeting**: Agenda rapat, Notulensi (Minutes of Meeting), Ringkasan diskusi
- **Email**: Draft profesional untuk komunikasi internal & eksternal

## Istilah Oil & Gas

Agent ini familiar dengan istilah industri EPC/Oil & Gas seperti:
- HSE, EPC, PMC, MOC, PPE
- FAT, SAT, WO, PO, LOI
- EOT, LD, NDE, WPS

## Cara Penggunaan

Agent ini menggunakan OpenHands SDK. Letakkan file `executive-assistant-epc.md` di direktori:
- Project-level: `.agents/agents/`
- User-level: `~/.agents/agents/`

## Contoh Prompt

```
Buatkan notulensi rapat HSE untuk proyek pipeline
Susun email konfirmasi jadwal dengan vendor EPC
Buatkan agenda meeting Review Progress Proyek Refinery
```
